# 套利研究与模拟

- 日期：2026-10-24
- 范围：按用户要求，将当前 Bot 协作能力与外部套利研究方向结合；只做研究、模拟和可核查记录。

## 为什么

DS Bot 已有长期身份、群聊、证据交流和角色权限。套利研究需要把数据采集、成本计算和风险复核分开，避免模型把屏幕价差当成实际收益。外部仓库只作为公开研究参考，代码和说明均原创，不复制或执行其中的内容。

## 已定的行为

- 只有用户要求时，Main Bot 调用 `setup_arbitrage_team`，创建三名普通成员和管理员先答的研究群。启动不预置成员，也不提升任何人的权限。
- 保存成员和群的 ID。重复调用复用已有身份，保留用户改名和指令；同名冲突在创建前拒绝，部分完成可重试。
- `evaluate_arbitrage` 处理同链、同一精确资产对、同一数量的两个现货场所。输入是调用者提供的来源、UTC 时间、深度、全量平均价和显式成本。
- 净收益扣除双边费用、双边进一步滑点预算、gas、其他费用和缓冲；所有金额使用同一个报价资产。费用缺失不按零处理。
- 过期、未来时间、不同步、深度不足、净收益不达门槛时记录拒绝原因。其他结果叫 `paper-candidate`，不代表成交。
- 保留最近 200 条共享模拟记录，包含来源、假设、计算版本和发起身份；`list_arbitrage_records` 查询。输入无效不入账，保存失败不返回成功。
- 新工具遵守已有 Bot 作用域和 Main Bot 权限检查，不进入普通 DSH Agent 的工具列表。

## 不做什么

不改 DSH，不引入第二套 Agent 运行时。不加载外部脚本，不连接钱包或发交易。不把资金费率、清算、跨链或闪贷套入现货价差公式。不声称已核实调用者提供的网页、报价或资产身份。

## 已知限制

- 第一期没有实时采集适配器、仓位回放或真实盈亏；模拟记录是决策快照。
- 使用 JavaScript 数字估算研究收益，拒绝非有限数和超出安全范围的值；不能用于构造交易数量。
- 最近 200 条以外的模拟记录会被丢弃。共享记录不是私聊，团队成员都能查看。
- 研究指令约束任务范围；实际工具权限继续由 DSH 的用户配置决定。
